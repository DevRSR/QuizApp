A responsive trivia quiz built with HTML, CSS, and vanilla JavaScript. Choose a category and difficulty, answer 10 Open Trivia DB questions against a 15-second timer, and see your score. Your best score is saved in the browser.

## Run

Open the project folder in a local web server (for example, VS Code Live Server), then open `index.html` in your browser. The quiz needs an internet connection to load questions from [Open Trivia DB](https://opentdb.com/).
